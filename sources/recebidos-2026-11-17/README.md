# Materiais recebidos para o projeto SIORG

Esta pasta reúne cópias dos arquivos que foram enviados durante o trabalho e das duas pastas de planilhas de órgãos e entidades. As cópias foram organizadas em 17 de novembro de 2026.

O arquivo `manifest.json` registra o nome original, o tamanho e o SHA-256 de cada cópia. Cada hash foi comparado com o arquivo de origem. As planilhas podem representar etapas diferentes do projeto e são materiais para confronto com os atos oficiais.

- `Planilhas_Secretarias` contém as 15 planilhas recebidas de secretarias e órgãos.
- `Planilhas_Autarquias` contém as cinco planilhas recebidas de autarquias.
- Os quatro documentos do compilado CMO contêm os 33 apontamentos de teste.
- Os arquivos SGGD e a Calculadora de Cotas preservam os modelos recebidos em diferentes momentos.
- O diagnóstico e o TXT da Linha do Tempo documentam os materiais enviados para revisão.

A base usada pelo aplicativo está em `src/data`. As fontes e as conferências estão em `evidence`. A situação atual dos ajustes está no documento de 17 de novembro em `outputs`.
